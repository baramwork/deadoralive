# Forecast Phase 0 — 사전등록 명세 (pre-registered, 2026-11-13)

결과를 하나도 보기 전에 고정한다. 바꾸고 싶은 것은 결과 뒤에 새 날짜의 새 명세로 쓴다
(`research/edge/CRITERIA.md`, `research/panic_dip/SPEC.md`와 같은 규율).

## 0. 검사하는 가정 — 단 하나

**"Cay는 본인이 흥미를 느끼는 소재(공인·정치·법적 결정·권력 분쟁)에서 시장보다 잘 맞힌다."**

R2(예보 미디어)·R3(흥미 소재 직접 베팅)이 이 가정 위에 서 있다. R4(market making)는 이 가정 위에 **서 있지 않다** —
하우스는 예측이 아니라 스프레드·자동화·리스크 관리로 벌기 때문. 따라서 이 실험의 결과는 R2·R3만 가르고 R4는 건드리지 않는다.

이 가정은 10/31에 합의되었으나 지금까지 한 번도 검사된 적이 없다.

## 1. 플랫폼과 벤치마크

| 역할 | 플랫폼 | 이유 |
|---|---|---|
| 기록 + 벤치마크 A | **Manifold** (play money) | 질문 수 많음, 해결 빠름, API. 기록은 실제 mana 베팅으로도 남겨 **제3자 타임스탬프** 확보 |
| 벤치마크 B | **Metaculus** community prediction | 예측 커뮤니티 집단지성, API |
| 참고 벤치마크 C | Polymarket / Kalshi 가격 (읽기만) | 같은 질문이 실돈 시장에 있으면 그 가격도 기록 — 더 강한 벤치마크 |

벤치마크 = "포캐스트를 입력한 그 순간의 시장 확률". 비교는 항상 **같은 시각의 쌍(paired)** 으로만 한다.

## 2. 질문 선정 기준 — 전부 만족해야 후보

1. **도메인 화이트리스트** (Cay 확정 필요): 공인·왕실·엔터테인먼트 / 정치(선거 결과뿐 아니라 인사·사임·스캔들·법안 통과 등 **결정**) /
   법적 결정(판결·기소·합의·규제 결정) / 기업·권력 분쟁(인수 성사, CEO 교체, 이사회 표결, 분쟁 합의).
2. **블랙리스트**: 가격·수치 시계열(주가·코인·금리·GDP 숫자), 스포츠 경기 결과, 날씨·과학 수치, 플랫폼 자기참조 질문("이 시장 거래량이…").
3. **해결 기한**: 포캐스트 시점부터 **14~90일**. (너무 짧으면 뉴스 속도 싸움, 너무 길면 12~16주 안에 해결 안 됨.)
4. **벤치마크 유효성**: Manifold 트레이더 ≥ 25명 **또는** Metaculus 예측자 ≥ 20명. 미달이면 시장가가 노이즈라 "이겼다"가 성립 안 함.
5. **정보량**: 포캐스트 시점 시장가가 **5%~95% 사이**. 0/100 근처는 이길 여지가 없다.
6. **anchoring 차단**: 선택·입력은 **가격을 보기 전에**. 도구가 제목·설명·해결 규칙만 보여주고 → Cay가 확률 + 근거 2줄 입력 →
   그 순간 도구가 시장가를 자동 기록. 입력 뒤에만 가격 공개.
7. **패스 허용**: 후보를 보고 "모르겠다/관심 없다"로 넘길 수 있다. 패스 수와 사유 한 단어도 기록(선택 편향 측정용 — 패스는 실제 예보자의
   정상 행동이므로 벌점 없음).

## 3. 양과 주기

- 주 **≥3건** 신규 포캐스트. 16주 상한 → 포캐스트 ≈ 48건, 해결 ≈ 30건 기대.
- 갱신(update)은 **새 행**으로 허용. 삭제·수정 불가. 1차 채점은 **첫 포캐스트** 기준(§5).
- Cay 시간 비용: 질문당 15~30분 × 3 = **주 1~1.5시간** + Claude 브리프 읽기.

## 4. 분업과 봉인 순서 (질문 1건당)

1. 도구가 후보 제시(가격 숨김).
2. **Claude 브리프**: 사실관계·일정·관련 인물·과거 유사 사례만. 확률 의견 없음.
3. **Claude 독립 예보**: 같은 브리프에서 Claude가 확률을 내고 **봉인**(Cay에게 안 보여줌).
4. **Cay 예보**: 확률 + 근거 2줄 + "핵심 불확실성 1개".
5. 도구가 시장가(A·B·C) 기록, Manifold에 mana 베팅(선택, Cay 핸들), Claude 예보 봉인 해제.

3번이 있어야 "Cay가 Claude 위에 무엇을 더하는지"가 분리된다 — R2 상품 설계에서 예보자가 누구인지 결정하는 데이터.

## 6. 채점

- **1차 지표**: ΔBrier = mean(Brier_cay) − mean(Brier_market) — 첫 포캐스트 기준, 같은 시각 paired. 벤치마크는
  해당 질문에 있는 것 중 **Manifold 우선, 없으면 Metaculus**(사전 고정; 실돈 가격은 참고 열).
- **2차 지표**: log score; 승률(질문별로 누가 결과에 더 가까웠나); 도메인별 ΔBrier; 캘리브레이션 표(10% 구간);
  **Cay vs Claude** ΔBrier; 갱신 포함 시간가중 Brier.
- **공개 채점**: GitHub Actions 주간 — Manifold/Metaculus API로 해결 상태 수집 → `forecast_log.csv` 채점 열 갱신 →
  정적 페이지(적중률·캘리브레이션·질문 목록). 이 페이지가 R2의 간판이 된다 — 기록을 버리지 않는다.

## 7. 판정 — 사전 고정

**중간 점검** (해결 ≥ 20건): 조기 **FAIL**만 가능 — ΔBrier ≥ +0.02 (시장보다 뚜렷히 나쁨)이면 중단. PASS는 중간에 선언하지 않는다.

**최종 판정** (해결 ≥ 30건 **또는** 16주 경과 중 먼저 오는 쪽):
- **PASS** = ΔBrier < 0 **AND** paired bootstrap(10,000회) 단측 p < 0.10 **AND** 승률 ≥ 55%.
- **FAIL** = 그 외 전부. 연장 없음.

솔직한 검정력 메모: 질문별 Brier 차이의 표준편차가 ~0.15라면 n=30에서 SE ≈ 0.027. 즉 ΔBrier가 −0.04 안팎은 되어야 PASS가 나온다.
그 정도 격차는 "시장보다 분명히 잘 본다"는 뜻이고, 그보다 작은 edge는 이 표본으로는 **증명 불가**이며 그 경우 FAIL로 처리한다
("증거 없음"이지 "없음 증명"이 아님 — 그러나 돈을 걸 근거로는 부족).
